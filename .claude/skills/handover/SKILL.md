# Хэндовер · Game Factory

Парный навык к `session-start`. **Чат - расходник, файл - источник истины**: что не попало в
файл, того не было. Начинать раньше, чем упрёшься в контекст.

## 1. Документы - в этом порядке

1. **`docs/CHANGELOG.md`** - запись сессии **сверху**: что сделано, таблица "Что | Как | Итог"
   (команда и её результат числом). Прошлые записи не трогать.
2. **`docs/STATE.md`** - переписать снимок целиком (D-052), не дописывать хвост:
   где мы, что не проверено, блокеры, следующий шаг, вопросы владельцу, ожидаемые числа
   тестов для следующего старта. ≤ 120 строк - иначе красный тест.
3. **`docs/DECISIONS.md`** - каждое решение сессии: что, почему, что отвергли, чьё (цитата
   владельца). Отменённое не удалять - "заменено D-0NN".
4. **`docs/PITFALLS.md`** - каждая грабля: симптом → причина → обход → где держится.
   Следующим номером, в раздел по теме.
5. По затронутому: `TESTING.md` (числа в "Что покрыто", строки мутаций), `SECURITY.md`
   (статус меры), `ROADMAP.md` (факт под пунктом - статус меняет только владелец),
   `GAMES.md`, `ARCHITECTURE.md`, `OPERATIONS.md`, `DEPLOY.md`.
6. Поменялся набор обязательного чтения или команды старта - этот навык и `session-start`:
   устаревший навык уводит следующую сессию так же, как устаревший STATE.

## 2. Проверки - числом, а не словом "зелёные"

```
pnpm typecheck && pnpm test     # включает тест ссылок, тест публичного репозитория, размер STATE
git diff --check
git status --short              # нет лишнего: .data, временные каталоги, правки Next в apps/hub
```

Код менялся - ещё `pnpm test:db` (при свободной памяти, П-043) и сборка игр по `CLAUDE.md`;
сборку хаба и e2e покажет CI после пуша.

**Публичный репозиторий (D-043).** Тест ловит адреса, пути и слова из списка; остальное -
глазами по списку "нельзя": ОС и версии ПО сервера, соседние сервисы, имена пользователей,
ключей и хостов, правила файрвола, незакрытые дыры, номера задач приватной базы.

## 3. Коммит и пуш

- Коммит - только после явного "да" владельца на **этот** коммит. Спросить прямо:
  "Делаю коммит?". Один коммит на сессию, в `dev`.
- Сообщение - по-русски, заканчивается сутью изменений; **никаких трейлеров** (соавторство,
  "сгенерировано", имя сессии).
- Пуш агенту закрыт сторожем - отдать владельцу блоком: машина, пользователь, оболочка
  (у пользователя агента - fish), команды по строке.
- Уже отправленный коммит правится новым коммитом сверху, без `--amend` и форс-пуша.
  Перед `--amend` неотправленного - `git fetch`: пуш делает владелец, отправлен ли - не видно.

## 5. Блок "Хэндовер" - последним

```
Хэндовер · сессия №N · YYYY-MM-DD
Сделано: <2-4 пункта>.
Проверено: <команды и числа>.
Не проверено: <что и почему>.
Коммит: <хеш или "ждёт да">; пуш: <сделан владельцем / блок выше>.
Дальше: <следующий шаг из STATE>.
```
