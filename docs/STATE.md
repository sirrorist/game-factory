## Хэндовер: новая сессия

Начать с навыка `session-start`, закончить - `handover`. Ожидаемое на старте: `pnpm test` -
102 / 102; `pnpm test:db` - 13 / 13 (только при свободной памяти ≥ 2 ГБ, П-043; CI - всегда). Пуш - блоком владельцу; в `main` = выкладка на прод через
≤ 15 минут: красный CI не выкладывается, игра без смены `version` - тоже (П-034). Коммит - по "да"
в реплике владельца, без префиксов (правило кита). Сабагентов - только по согласию владельца.

- Домен игр сейчас `*.play.youranus.ru`; новый домен - перед открытием (D-010).
- Коммит - в `dev`, один на сессию; в `main` - перемоткой и отдельным "да" (D-042).
- Метка содержимого (`contentTag`) - в ETag игр и обложки; на ней держится `check-prod` (D-044).
- Изоляция прода (D-038): хаб и сервер игр без интернета; база - в сети `gf-db` (D-051).
- Миграции только расширяющие, перед каждой - дамп (D-051). Лимит моста - на вкладку (D-050).
- Вход (D-058): куки только `__Host-` (П-052); CSRF - `proxy.ts`, Origin = `GF_HUB_ORIGIN`;
  хаб - ролью `gf_hub`, роль ставит `migrate`; владелец - `admin.ts` в `migrate`; формат строки
