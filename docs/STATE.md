## Хэндовер: новая сессия

Начать с навыка `session-start`, закончить - `handover`. Ожидаемое на старте: `pnpm test` -
77 / 77, `pnpm test:db` - 8 / 8 (только при свободной памяти ≥ 2 ГБ, П-043; в сессии №8 не
запускали - памяти не хватало, код базы не менялся). Пуш - блоком владельцу; в `main` = выкладка на
прод через ≤ 15 минут: красный CI не выкладывается, игра без смены `version` - тоже (П-034).
Сабагентов на проверку не запускать без согласия владельца (лимиты) - помечать долгом здесь.

Контекст решений, который легко потерять:
- Игры собираются в CI, сервер только публикует (D-034); прод-конфиг - копии root (D-035).
- Веб - на отдельном адресе сервера (D-036). Репозиторий и образы публичные (D-037).
- Домен игр сейчас `*.play.youranus.ru`; новый домен - перед открытием (D-010).
- Офлайн-архив - только для статических игр (D-012). Хаб - гость без авторизации (D-024).
- Коммит - в `dev`, один на сессию, с "да" владельца; в `main` - перемоткой и отдельным "да"
  (D-042). Минуты CI беречь (D-031).
- Метка содержимого (`contentTag`) - в ETag игр и обложки; на ней держится `check-prod`
  (D-044) - формат ETag не менять молча.
- Изоляция прода (D-038): хаб и сервер игр без интернета и без соседей; база - в сети `gf-db` (D-051).
- Бэкап базы опирается на имя проекта, сервис `db`, роль и базу `gf`, замок `gf-update` и мажор
  Postgres - менять только с записью в приватной базе инфраструктуры (OPERATIONS.md).
- Миграции только расширяющие, перед каждой - дамп (D-051). Лимит моста - на вкладку (D-050).
- `k8s-at-home`: id блоков - байты сохранения, менять нельзя, новые - в конец (`blocks.ts`);
  мир - из сида, сохраняются только правки (D-054). Тесты игр - `games/*/test`, гоняет `pnpm test`.
