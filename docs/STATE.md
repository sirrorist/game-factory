## Хэндовер: новая сессия

Причина новой сессии: в этой `registry.npmjs.org` так и остался закрыт (П-014).

1. Первая строка ответа — канарейка (правило кита), нумерация ходов с 1.
2. Прочитать `CLAUDE.md`, этот файл, `docs/ROADMAP.md` (этап 0б), `docs/PITFALLS.md`.
3. Проверить сеть: `curl -sS -o /dev/null -w '%{http_code}' https://registry.npmjs.org/zod`
   — ждём `200`. Иначе — сказать владельцу и работать без зависимостей.
4. `pnpm install && pnpm check` — должно совпасть с таблицей «Что проверено» выше
   (37 юнит, 6 e2e). Если в контейнере `playwright` другой версии, чем Chromium в
   `/opt/pw-browsers`, — `executablePath: '/opt/pw-browsers/chromium'` вместо скачивания.
5. Проверить, что CI последнего коммита в `main` зелёный.
6. Дальше — этап 0б. Первым коммитом сессии — lockfile, чтобы CI стал `--frozen-lockfile`.
