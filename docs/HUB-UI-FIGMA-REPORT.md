## Состав и связь с кодом

Три страницы: References, Components, Layouts. 52 main components, четыре component
set: Button, Navigation item, Header, Popup surface. Среди них шесть пресетов данных
карточки, шесть обложек, логотип/бренд, проектные иконки, теги, версия и кнопка «…».
15 основных размеров каталога и восемь дополнительных состояний/тем — 23 фрейма.
Макеты используют instances, Auto Layout, блокировку пропорции обложки и GRID
с долями `1fr 1.65fr` для действий. Растровые картинки внутри макетов — только
отдельные обложки; нет изображения всего интерфейса под декоративными слоями.

114 переменных: 50 primitives, по 25 semantic для Night/Day, 14 metrics.
Проверено: 50 semantic aliases, нет `ALL_SCOPES` и переменных без WEB code syntax.
12 text styles: Onest, Unbounded, JetBrains Mono; два effect styles.
Цвета/шрифты взяты из `apps/hub/src/app/globals.css`, роли/радиусы из `design.css`,
логотип из `app/icon.svg`, иконки из `components/icons.tsx`.
Обложки шести реальных игр отрендерены из исходных SVG отдельно в 960×540;
все шесть upload получили HTTP 200, image fills используют FIT.

Сопоставление при будущем переносе: Card → существующая разметка каталога и
`.gf-card*`; Button → `.gf-btn*`; Tag/More → `GameTags`; Header/Navigation →
существующая шапка; Popup surface → новая общая основа всплывающих поверхностей.
Имена `--catalog-body-gap`/`--catalog-action-height` — предлагаемые токены для
будущего CSS, пока не объявлены в приложении. Остальные WEB-имена соответствуют
существующим переменным. Это не автоматический Code Connect и не двусторонняя
синхронизация исходников.

У Starter подтверждены ограничения: три страницы, один mode на коллекцию.
Night и Day сделаны раздельными коллекциями, Day-фреймы используют явные bindings.
Последний повторный экспорт упёрся в лимит MCP-вызовов Starter; обходов не было.

## Проверки и ограничения

Открыты итоговые PNG: phone314, phone390, desktop1920, landscape,
landscape-scrolled, drawer314, day390, components. Исправлены подтверждённые
дефекты сборки Figma: объединённые defaults названий/описаний, фиксированная
высота cover при изменении ширины, неравномерное заполнение действий, размер
рисунка иконок, заголовок Drawer и лишняя иконка у выхода.

MCP-export не показывал ellipsis при нативном textTruncation/maxLines: поэтому
отображаемые строки Figma измерены Onest14/20 и сокращены по словам с «…».
138 instances, 72 разных измерения. Полное описание остаётся в game.json и
description main component. **В приложение переносить полный текст + CSS clamp,
не эти сокращённые строки.** Типографика и геометрия проверены после поправки.

Motion: menu translateX+opacity, dialog translateY/scale+opacity, toast
translateY+opacity, scrim fade. Вход320ms (toast200), выход200ms, easing из
`--ease-out`. Видео Drawer экспортировано320px/10fps/2s, открыты кадры
0/0,2/0,6/1,3/1,6s: исходное состояние, вход, открытое, выход и закрытое.
Hold до1,2s — только демонстрация. Dialog/Toast tracks прочитаны обратно,
их видео не экспортированы. Reduced motion представлен отдельным статическим
открытым состоянием. Это timeline-демонстрации, не проверенные кликабельные
браузерные попапы и не доказательство наследования анимаций React-компонентом.

Независимый read-only просмотр `menu_prototype_review` открыл восемь PNG и три
эталона. Блокирующих визуальных дефектов не обнаружил; готово к оценке владельцем.
Единственную косметическую заявку — синие пиксели у menu/close — основной агент
сверил с `ICONS.menu.px`/`ICONS.close.px`: это намеренные части проектных иконок,
сохранены. Отличаются от простого бургера прежнего прототипа C.

**Последняя поправка focus**: в Figma записаны отдельные outline2 с offset3,
overflow visible; вернулось структурное подтверждение. Повторный снимок
заблокирован лимитом MCP Starter, поэтому эта поправка визуально не проверена;
`components.png` показывает состояние до неё. Нужна ручная проверка фрейма9:323.

Не проверены в этом этапе: настоящий Next/iframe, адресная строка телефона,
DOM/touch/focus, увеличенный текст, длинные данные, взаимодействия меню,
прочие страницы и CI. Из Figma нельзя вывести, что эти пункты пройдены.
Независимый просмотр макетов не заменяет финальное независимое UI-ревью сайта.

Локальные результаты: `test-results/ui/hub/figma-handoff-20261019/design-v1/`:
PNG, `drawer-motion.mp4`, монтаж пяти фаз, measurement/state JSON, SHA-256,
копии скриптов построения и ledger для продолжения. URL экспорта с подписью
не включены в отчёт. Обычные тесты кода в этом этапе не запускались — приложение
