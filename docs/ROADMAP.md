## Этап 1 - хаб "по-взрослому" ⬜

- Postgres + Drizzle: реестр игр и версий переезжает из `registry.json`
- Авторизация (Better Auth): владелец, позже игроки; сессионная кука `__Host-`
- Сохранения и очки через API хаба; лидерборды в Valkey
- Защита от CSRF токенами и проверкой `Origin` (SameSite не спасает, PITFALLS.md)
- Серверная проверка правдоподобия очков (rate-limit, пределы из манифеста)

## Этап 2 - админка и хранилище ⬜

- MinIO локально; профили хранилищ (endpoint, регион, бакет, ключи) с шифрованием
  ключей мастер-ключом из файла `600`
- Загрузка игры zip-архивом: защита от zip-slip, zip-бомб, симлинков, лимиты
- Версии в админке: публикация, откат (переключение указателя), снятие
- Журнал действий админки, вход по passkey или 2FA
- Builder: сборка в контейнере без сети, кроме зеркала npm (Verdaccio), очередь BullMQ

## Этап 3 - игры с бэкендом ⬜

- `kind: "server"`: Dockerfile, порт, ресурсы в манифесте
- Game Runtime: контейнеры (gVisor), лимиты, закрытый выход в сеть, сон при простое
- Короткоживущий токен игры (audience = id игры) вместо ключей хаба
- Шаблон Colyseus для мультиплеера
- Экспорт серверной игры как `docker-compose.yml` + статика

## Этап 4 - ИИ-студия ⬜

- `templates/` для каждого toolchain, `skill-packs/` под жанры (формат - как в `global-agent-kit`)
- Агент на Claude Agent SDK внутри песочницы Builder'а; ключ API - через прокси хаба
- Превью-скриншот через Playwright, публикация по кнопке, отдельного пути в прод у ИИ нет

## Слабые места - на будущее

Записаны по обзору 2026-09-25 (сессия №3). Не баги сегодня, а то, что ударит позже.

- ⬜ **Документы опережают реальность.** STATE №2 утверждал "репозиторий публичный" (был
  приватным), спецификация считала, что агент на VPS видит Docker, и собирала игры на сервере
  с 1,5 ГБ свободной памяти. Мера: факт о внешнем мире - только с командой проверки; сессия,
  которая не может проверить (облако ↔ сервер), пишет "предположение", а не "проверено".
- ⬜ **Документов много относительно кода** (~1,6 тыс. строк на ~650 строк ядра). Когда поиск
  по `D-`/`П-` начнёт повторяться - завести индекс "ID → файл:строка", как в `infra-ctl`.
- ⬜ **Нет наблюдения за продом.** Сертификаты `games` и `*.play` - в `cert-expected.list`
  инфраструктуры; алерт на падение `gf-update` и на недоступность хаба. Делается в T-179 `infra-ctl`.
- ⬜ **Обновление движка останавливает выкладку** (П-034). Правильно, но легко забыть: при
  PR Dependabot по Phaser/Three/Vite - поднимать `version` затронутых игр в том же коммите.
  Возможная автоматизация: CI сравнивает хеш собранной игры с опубликованным в проде.
- ⬜ **e2e только в Chromium**, WebGL - программный. Firefox/WebKit и телефон - до открытия.
- ⬜ **Бэкапа тома нет** (осознанно, воспроизводим из образов). Пересмотреть, как только в
  томе появится то, чего нет в образах: загрузка игр (этап 2), сохранения на сервере.
