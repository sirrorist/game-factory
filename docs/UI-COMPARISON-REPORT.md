# Перенос сравнения сайта и игр на уровень проекта

Владелец разрешил перенос, коммит и push текущей ветки game/superwalk после приёмки
исправлений Superwalk R1–R5. Публикация и отложенная серверная экономика не входят в задачу.

Общий инструмент находится в `tests/ui/`, инструкция — [README](../tests/ui/README.md).
Профили, защищённая сборка баз, история результатов, evidence, PNG diff и сервер двух
версий вынесены в core. Сайт и специальные игровые сценарии находятся в targets/hub
и targets/superwalk. CLI автоматически находит игровые манифесты и адаптеры;
прочие static/vite-ts игры получают сравнение стартового экрана без адаптера.

Команды из корня: ui:list, ui:baseline, ui:preview, ui:check, ui:compare, ui:verify,
ui:live и дополнительные команды адаптеров. --run создаёт отдельное сравнение для задачи.
Старые команды пакета Superwalk делегируют общему CLI. В обычную сборку игры хук не добавляется.

## Dev и сохранность

- Только явный запуск отдельной командой; слушается 127.0.0.1, NODE_ENV=production запрещён.
- Прод-команды и compose не подключают сравнение. Весь tests/ уже исключён из Docker-контекста;
  изменение Docker/compose и новый прод-сервис не потребовались.
- База неизменна, повторное создание отклоняется. Перед заменой after архивируются
  артефакты/отчёты/PNG; новый after публикуется из чистого stage, без старых ресурсов.
- Падение проверки сохраняет диагностику и снимает полный зелёный статус.
- UI-моки сайта используются только временной dev-сборкой. Настоящий вход/API не подменялись.
- Программная сборка Vite возвращает исходный NODE_ENV после завершения, чтобы её побочный
  эффект не мешал следующей dev-проверке. Прямой production-запуск остаётся запрещён.

Прежние результаты Superwalk и исходники инструмента сохранены в
`test-results/project-ui-migration/legacy-superwalk-results/` и `legacy-superwalk-tool/`.

## Проверки

- `pnpm typecheck` — прошёл для всего проекта.
- `pnpm test` — 276/276, включая семь новых тестов dev-инструмента и проверку публичного репозитория.
- `pnpm ui:check hub` — 308 состояний, failed:0; обе темы и семь размеров.
- `pnpm ui:check superwalk` — 322 состояния, complete:true, failed:0; 161 diff.
- `pnpm ui:boundary superwalk` — 192 состояния, complete:true, failed:0 на финальном шаблоне.
- ui:verify: сайт и обычная игра — по четыре проверки просмотрщика; Superwalk — восемь
  проверок переключения, viewport, защиты базы и побайтной повторяемости. Они прошли.
- `pnpm ui:smoke` — финальный общий viewer, три цели и восемь наблюдений: complete:true,
  failed:0. Проверены темы сайта внутри обоих iframe, viewport и отсутствие пустого
  выбора темы у игры. Перед проверкой наследования темы отключена глобальная media-эмуляция
  Playwright; это не подмена CSS сайта или результата проверки.

Обычная игра без адаптера проверена через отдельную базу snake/project-tool:14 состояний.
У обеих побайтно одинаковых версий обнаружено существующее переполнение поля в
844×390 (одна ошибка after и та же ошибка before); это не замаскировано ради зелёного отчёта.
Snake не изменялся. Результат — `test-results/ui/snake/runs/project-tool/report.json`.

Метаданные/снимки нового инструмента — в `test-results/ui/<цель>/`, независимая проверка —
`test-results/project-ui-migration/review.md`; общий browser-smoke.json и compare PNG — рядом.
Независимый проверяющий прочитал архитектуру, dev/prod-границы и доказательства,
открыл PNG. Найденные ошибки архивирования/сохранения fatal-диагностики исправлены.

Физические устройства, Safari/Firefox, настоящий вход/БД, полный повтор live-сценариев
игры и Windows этим переносом не проверялись. Ранее принятые live/R5-отчёты сохранены
как исторические, их hashes не переписаны под новый инструмент. Базы из старых commit
собираются установленными зависимостями worktree; нужна совместимость toolchain.
