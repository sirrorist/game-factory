# Ревью стилей и первого экрана хаба

Дата: 2026-10-16. База — `c1e1f8a`, незакоммиченные изменения рабочего дерева.
Независимое чтение выполнил отдельный агент `hub_styles_review`; адресные
браузерные сценарии исполнены основной сессией из-за ограничений sandbox.
Ревьюер не менял код, документы и базы. Исправление ниже выполнено основной сессией.

## Область

Весь текущий UI diff: каталог, страница игры, вход, аккаунт, Web kit, 404,
пустой каталог, общие стили и скроллбары dev-просмотрщика. Прочитаны также новые
компоненты CatalogLayout, FirstScreen, GameTags, PasswordHelp, KitNavigation
и планы приёмки. Проверялось сохранение атрибутов и подключения игрового iframe;
проверки безопасности API и авторизации в эту область не входят.

## Подтверждённая находка

**R1 / P2 — длинная допустимая версия расширяет страницу игры на телефоне.**

Источник: `apps/hub/src/app/design.css`, правило `.gf-game-metadata > .gf-badge`.
Новое `flex: none` оставляло плашку версии шире колонки. Валидатор манифеста
принимает semver с длинным суффиксом без ограничения общей длины.

Воспроизведение: сцена «Страница игры», viewport 320×844, touch/mobile Chromium;
заменить текст плашки на `v1.0.0-release-candidate.2026.10.16.feature-test`.
Данные реестра, исходная база и исходники для воспроизведения не менялись.

| Состояние | Ширина плашки | Правый край | Ширина документа |
|---|---:|---:|---:|
| Исходный снимок | 288 px | 304 px | 320 px |
| До исправления | 363.53 px | 379.53 px | 380 px |
| После исправления | 288 px | 304 px | 320 px |

При 390 px плашка до исправления выступала за колонку на 5.5 px.
Короткая `v1.1.1` и `v0.1.0-ui-preview.20261016.1234567890` проблемы не вызывали.

Исправление: ширина ограничена колонкой; длинный текст может переноситься,
высота плашки растёт. Повторное адресное воспроизведение на 320×844 прошло:
длинная версия занимает 32 px по высоте, короткая сохраняет 22 px.
Это перепроверка исполнителя, отдельного независимого повторного ревью не было.

## Остальные результаты

Других подтверждённых находок независимый ревьюер не сообщил.

- Иконки Web kit при 360×800: три колонки, подписи целиком, ширина документа 360 px.
- Аккаунт 844×390: уведомление ошибки добавления не закрывает кнопки удаления;
  проверены попадания в кнопки и снимок. Уведомление временно перекрывает часть
  подписи второго ключа, закрытие уведомления доступно.
- Страница игры после resize: 844×390, 640×540, 639×540, 960×540, 1024×481.
  На этих размерах горизонтального переполнения нет. После стабилизации размеров
  в течение 350 ms нет повторных изменений атрибута style основного блока.
- Каталог после resize: 639×844, 640×844, 960×768 — без горизонтального переполнения.
  Это проверка переполнения, не подтверждение всех требований к видимой доле карточек.
- Попап тегов: Enter открывает, фокус на «Закрыть»; Escape закрывает и возвращает
  фокус на кнопку «…».
- В адресном прогоне ошибок JavaScript не зарегистрировано. Сборка превью после
  исправления и `git diff --check` прошли.
