# Независимая перепроверка синхронизации iframe — R1

2026-10-16. **Остаток R1 устранён в проверенных условиях. Новых подтверждённых проблем
в адресной перепроверке не обнаружено. R1–R3 из исходного ревью закрыты в ранее
обозначенной области проверки.**

Проверены незакоммиченные изменения относительно bd0b874, применимые инструкции,
[отчёт об исправлении](UI-COMPARISON-R1-FRAME-FIX.md), `compare.html`, чтение artifactHash
в `core/server.ts` и новый browser-сценарий. Исходники игр, UI хаба и production-конфигурация
по-прежнему не изменены. Код, прежние отчёты, базы и доказательства не менялись;
добавлены этот документ и новые артефакты. Deploy/merge/commit/push не выполнялись.

## Собственные проверки

- `pnpm test` — **277/277**.
- `pnpm ui:regression` — **8/8**, включая новый сценарий синхронизации кадров,
  прежний аварийный viewer и свежие отрицательные CLI-прогоны Snake/Superwalk.
  Имена проходов уникальные; старые доказательства не заменялись.
- `pnpm typecheck`, `pnpm ui:typecheck`, `git diff --check` — успешно.
- Отдельный собственный сценарий `test-results/review-r1-frame-recheck/probe.mjs`
  прошёл в Chromium 153.0.8010.12, без ошибок JavaScript. Использованы настоящий сервер
  сравнения, `publishSnapshot()`, `snapshotEvidence()` и проверка актуальности отчёта.

В независимом сценарии повторён именно прежний отказ: открытый viewer, новая успешная
сборка и ожидание автоматического опроса без ручного reload. Дополнительно проверены
ресурс CSS, сохранение сеансов и промежуток незавершённой навигации.

| Сценарий | Наблюдение |
|---|---|
| Успешная замена HTML BUILD 2 → BUILD 3 | Версия/ref, маркер в after и успешный отчёт согласованы; boot-id after изменился, before сохранился |
| Повторные опросы и перезапись только report.json | Оба boot-id сохраняются |
| Изменение только style.css при прежнем SHA HTML | CSS реально изменился с rgb(10,20,30) на rgb(200,210,220); after перезагрузился, before сохранился |
| Искусственно задержанная навигация к BUILD 4 | Старый after имеет visibility:hidden, вместо успеха показано «Загружается выбранная сборка…»; before не перезапущен |
| Завершение задержанной навигации | Показан BUILD 4, затем возвращается успешный статус |
| Режим «Играть», BUILD 4 → BUILD 5 | Новый документ загружен автоматически с live=1; before сохраняет сеанс |
| Опрос и перезапись отчёта в режиме «Играть» | Оба сеанса сохраняются |

Выбранные `scene=other`, `touch=1`, viewport 844×390, светлая тема и режим просмотра
сохраняются при автоматическом обновлении. Намеренное переключение в «Играть» сначала
загружает оба документа с новым режимом; после этого неизменная колонка не перезапускается.

Полные UI/live-матрицы игр и хаба, настоящее прохождение и auth/API/bridge, физические
устройства, Safari/Firefox, Windows и Docker-образы повторно не проверялись. Прежним
отчётам не присваивались новые fingerprints. R2/R3 дополнительно покрыты повторным
прохождением существующих регрессий; полный объём их прежней перепроверки не повторялся.

**По проверенному остатку R1 дополнительных исправлений не требуется.**
