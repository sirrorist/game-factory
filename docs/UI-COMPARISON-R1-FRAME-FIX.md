# R1: синхронизация загруженного iframe с успешной пересборкой

2026-10-16. Адресное исправление оставшегося P2 из
[перепроверки R1–R3](UI-COMPARISON-FIXES-RECHECK.md).
Предыдущие отчёты и доказательства сохранены без изменений.

Причина: конфигурация и успешный вердикт обновлялись при опросе, а уже открытый
документ iframe продолжал жить до ручного reload. Проверка неуспешной пересборки
этот сценарий не покрывала.

## Изменение

Сервер добавляет к snapshot хеш всего каталога артефактов. Просмотрщик сравнивает
его с загруженной версией каждой колонки. Изменившаяся сборка автоматически
перезагружает соответствующий iframe, в том числе в режиме «Играть»; неизменная
колонка сохраняет сеанс. Учитывается изменение CSS/ресурсов при прежнем HTML.

Обычный опрос и обновление одного отчёта при прежних файлах не перезапускают игру.
Выбранные экран, размер, тема и режим сохраняются. На время навигации прежний кадр
скрыт, а вместо успешного вердикта показывается «Загружается выбранная сборка…».
Это исключает показ старого документа рядом с успехом новой версии при её загрузке.

## Проверка

Новый сценарий `tests/ui/check-failures.browser.ts` оставляет viewer открытым и
записывает завершённый успешный report с актуальным `snapshotEvidence()`:

- После BUILD 1 → BUILD 2 подпись версии, ref и содержимое after соответствуют
  новой сборке без ручного reload. Сеанс before не перезапущен.
- Последующие опросы и перезапись успешного отчёта оставляют boot-id прежним.
- Изменение только style.css обновляет документ и его CSS при прежнем hash HTML.
- В режиме «Играть» неизменный опрос сохраняет сеанс, BUILD 3 загружается
  автоматически с параметром live=1; before остаётся прежним.
- Сохраняются выбранные экран, профиль 844×390 и тема. Ошибок JavaScript нет.

`pnpm ui:regression` — **8/8**: новый сценарий, прежняя проверка аварийного viewer
и четыре контрольных отказа CLI для Snake/Superwalk. `pnpm ui:test` — **8/8**;
`pnpm test` — **277/277**. `pnpm typecheck`, `pnpm ui:typecheck` и `git diff --check` прошли.

Собственные доказательства:
`test-results/ui-review-fixes-r1/frame-sync-HzahB8/observations.json`,
`html-rebuild.png`, `live-rebuild.png`. В JSON сохранены версия, маркер документа,
boot-id обеих колонок, CSS и вердикт для четырёх фаз. PNG открыты отдельно.

Изменения относятся только к dev-инструменту и его документации/тесту. R2/R3,
исходники игр, UI хаба и production lifecycle не менялись этим дополнением.
Полные игровые UI/live-матрицы, физические устройства, Safari/Firefox и Windows
не проверялись заново. Проверка — Chromium с синтетическими сборками,
использующими настоящие сервер сравнения, `publishSnapshot()` и проверку evidence.
