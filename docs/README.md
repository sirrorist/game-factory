## Правило документов

- **Факт - с источником.** "проверено: `pnpm test`, 59 / 59" лучше "всё работает".
- STATE переписывается, CHANGELOG, DECISIONS и PITFALLS дописываются. Отменённое решение не
  удаляется - помечается "заменено D-0xx". Грабля - в раздел по теме, следующим номером.
- Документ, расходящийся с кодом, - баг. Правится в том же коммите, что и код.
- Ссылки `D-`/`П-` и размер STATE держит тест `tools/docs.test.ts`: висячая ссылка, повтор
  номера или STATE длиннее 120 строк - красный `pnpm test`.
- Репозиторий публичный: о сервере - только то, что разрешает D-043; адреса, пути и слова из
  списка ловит `tools/public-repo.test.ts`.
