## Правило документов

- **Факт — с источником.** «проверено: `pnpm check`, 37+6 тестов» лучше «всё работает».
- STATE переписывается, DECISIONS и PITFALLS дописываются. Отменённое решение не
  удаляется — помечается «заменено D-0xx».
- Документ, расходящийся с кодом, — баг. Правится в том же коммите, что и код.
