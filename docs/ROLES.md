# Роли агентов - план

> Статус: **план** (D-020). Сделана одна роль - "Безопасность" (D-045, D-046); остальные -
> когда появится повторяющаяся потребность.

## Принцип

**Проверяет не тот, кто писал.** Роли разведены, чтобы проверка не подтверждала сама себя.
Инструкции ролей - общие для всех проектов и живут в `global-agent-kit/roles/`;
здесь - только **факты этого проекта**, которые роль получает на вход.

Уже есть в ките: `REVIEWER`, `TESTER`, `DESIGNER`, `ACCEPTANCE`, `SECURITY`.
Нужно добавить в кит: `PLANNER`, `ANALYST`, `DEVELOPER`, `DOCS`.

## Роли

| Роль | Что делает | Вход | Выход | Правит | Нельзя |
|---|---|---|---|---|---|
| **Планировщик** (PLANNER) | режет цель на задачи с критериями готовности | цель владельца, ROADMAP, STATE | задачи в ROADMAP: что, критерий, как проверить | ROADMAP (новые задачи) | менять статусы этапов без "да" |
| **Бизнес-аналитик** (ANALYST) | превращает "хочу" в требования и сценарии | запрос владельца | сценарии пользователя, ограничения, вопросы | `docs/requirements/` | придумывать ответы за владельца |
| **Разработчик** (DEVELOPER) | пишет код и тесты по задаче | задача с критериями | код + тесты + обновлённые документы | код, тесты, docs | закрывать задачу самому |
| **Тестировщик** (TESTER, кит) | пишет и гоняет тесты на чужой код | задача, код | отчёт: что упало, что не проверено | только тесты и фикстуры | чинить боевой код, ослаблять тест |
| **Ревьюер** (REVIEWER, кит) | читает diff, ищет ошибки | diff, ARCHITECTURE, инварианты CLAUDE.md | находки с адресом строки и цитатой | ничего | править код |
| **Безопасность** (SECURITY) | сверяет изменение с моделью угроз | diff, SECURITY.md | находки + какой пункт чек-листа задет | ничего | снижать меры "ради удобства" |
| **Дизайнер** (DESIGNER, кит) | интерфейс хаба и админки | экраны, сценарии | предложения: экран, состояние, как проверить | макеты, `docs/design/` | трогать логику |
| **Приёмщик** (ACCEPTANCE, кит) | сверяет результат с критериями | критерии, результат, вывод команд | вердикт: принято / нет и почему | ничего | доделывать |
| **Хранитель документов** (DOCS) | следит, что docs совпадают с кодом | diff, docs | список расхождений | docs | менять смысл решений |

## Конвейер задачи

```
владелец → АНАЛИТИК → ПЛАНИРОВЩИК → РАЗРАБОТЧИК → ТЕСТИРОВЩИК ─┐
                                                  РЕВЬЮЕР ─────┼→ ПРИЁМЩИК → владелец ("да" на коммит)
                                                  БЕЗОПАСНОСТЬ ┘
```

Мелкие задачи идут коротким путём: разработчик → ревьюер → приёмщик.
Всё, что трогает play-server, мост, SDK, `deploy/`, загрузку или авторизацию, - обязательно
через "Безопасность".

## Роль "Безопасность" - как звать

- Сабагент `.claude/agents/security.md` - тонкая обёртка: читает инструкцию кита
  `global-agent-kit/roles/SECURITY.md` и накладывает факты проекта (модель угроз, инварианты,
  потоки недоверенных данных). Нет инструкции кита - роль отказывается работать, а не
  работает по памяти.
- Вход - диапазон коммитов или патч; выход - JSON: находка с адресом, цитатой, задетым
  пунктом `SECURITY.md`, актором и сценарием атаки; `not_checked`.
- Отчёт - заявка: каждую находку зовущий открывает по адресу, прежде чем чинить.
- Роль проверена мутацией (STATE, сессия №6): на патче с подброшенными дырами в мосте
  обязана их найти, на чистом коммите - не выдумать `critical`/`high`.

## Как это будет устроено технически

- Роли - сабагенты Claude Code (`.claude/agents/<role>.md`), тонкие обёртки над
  инструкциями кита + ссылки на документы проекта.
- Границы роли - сторожем `guard-role.sh` из кита (хук `PreToolUse`), а не просьбой:
  ревьюер физически не может вызвать `Edit`.
- Отчёт роли - заявка, а не результат: зовущий проверяет каждую находку по адресу
  (правило из `global-agent-kit/roles/README.md`).

## Для ИИ-студии (этап 4)

Те же роли пригодятся внутри студии: планировщик режет "сделай платформер" на задачи,
разработчик собирает игру из шаблона и набора скиллов, тестировщик гоняет e2e через
`file://` и в хабе, приёмщик сверяет с описанием. Конвейер тот же - поэтому роли
проектируются сразу переносимыми.
