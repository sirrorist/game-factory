## Первый экран каталога

Количество карточек указано по высоте одной колонки при прокрутке в самом верху.

| Экран | Карточек по высоте | Особенность |
|---|---|---|
| Телефон, портрет 390×844 | Первая целиком, у второй обложка и название | Описание второй начинается за нижней границей экрана; высота учитывает размер кнопок для мыши и касаний |
| Телефон, ландшафт 844×390 | Первоначально примерно ½ | Без дополнительного промежутка над карточками; после прокрутки шапки карточка целиком помещается по высоте экрана |
| Планшет, портрет 768×1024 | 2 | Две колонки |
| Планшет, ландшафт 1024×768 | 1¼ | Две колонки |
| ПК, Full HD / QHD / 4K | 2 | Три колонки: шесть целых карточек на первом экране |

Размеры зависят от доступной высоты после фактической шапки и заголовка каталога.
Карточки одинаковы внутри раскладки; читаемый текст и кнопки сохраняют минимальные
размеры. При увеличенном шрифте или меньшем экране доступность содержимого важнее
указанного количества. Лишние карточки доступны обычной прокруткой.

## Шаги

1. Откатить прежнее центрирование отдельной страницы игры и общую оболочку.
   Оно было сделано из-за неверно понятой области задачи.
2. Собрать раскладку каталога под указанные пропорции: компактные отступы,
   одинаковые карточки, описание до трёх строк, название до двух строк;
   заголовки, описания и действия выровнены между карточками.
3. Теги в одну строку: целые плашки, кнопка … при переполнении, попап всех тегов
   с закрытием кнопкой, снаружи и Escape. Поиск по тегам — отдельная задача.
   Высота кнопки … совпадает с высотой тегов. Нижние кнопки действий заполняют
   доступную ширину карточки; сами теги сохраняют ширину по содержимому.
   Попап появляется плавно за 180 ms; при сокращённой анимации эффект отключён.
   Внешняя тень и штатное проваливание «Играть» сохранены. Высота поверхности
   уменьшена на высоту тени: вместе они совпадают по высоте со «Скачать».
4. Версия справа снизу на обложке: единый стиль, тёмная полупрозрачная подложка,
   blur и светлый моноширинный текст. Индивидуальные цвета карточек можно обсудить
   после приёмки общего варианта; данные манифеста сейчас не расширяем.
5. Приёмка каталога владельцем — принята в чате. Это не подтверждение полного
   автоматического прогона или проверки на физических устройствах.
6. **После приёмки каталога:** определить аналогичные правила для всех остальных
   страниц хаба. Для каждой страницы отдельно перечислить primary-контент и
   основные действия, которые должны целиком помещаться на первом экране в каждом
   разрешении; второстепенное содержимое оставить ниже. Согласовать таблицу с
   владельцем и применять по страницам. Количество карточек каталога на другие
   страницы механически не переносить. Встроенные интерфейсы игр — отдельная задача.
