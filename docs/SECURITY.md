## Кого боимся

| Кто | Что может | Когда актуально |
|---|---|---|
| Игра с ошибкой | сломать себя, завалить хаб сообщениями | уже |
| Зависимость игры (npm) | выполнить код при сборке, украсть секреты сборщика | этап 0б+ |
| Вредоносная игра от пользователя | XSS хаба, кража сессий, фишинг, майнинг, побег из контейнера | этап 5 |
| Промпт-инъекция в ИИ-агента | заставить агента вынести секреты или опубликовать мусор | этап 4 |
| Внешний сайт | встроить игру для кликджекинга, подделать сообщения | уже |

Сейчас игры пишет только владелец, но изоляция строится как для чужого кода: на
старте это почти бесплатно, а встраивать её потом в работающую систему очень дорого.

## Загрузка игр (этап 2)

- 🔜 Zip-slip: имена с `..`, абсолютные, с `\` - отказ.
- 🔜 Zip-бомба: лимит размера после распаковки и степени сжатия, лимит числа файлов.
- 🔜 Симлинки внутри архива - отказ.
- 🔜 Чтение архивов - проверенной библиотекой, не самописным парсером (D-013).

## Сборка и контейнеры (этапы 2-3)

- 🔜 Без lockfile сборка не запускается; `--ignore-scripts`; сеть - только зеркало npm (Verdaccio).
- 🔜 Контейнеры: не root, файловая система только для чтения, `cap-drop ALL`,
  `no-new-privileges`, лимиты на процессы, CPU и RAM, таймаут.
- 🔜 **Docker-сокет не монтируется никуда и никогда** - это root на хосте.
- 🔜 Контейнер игры не видит внутреннюю сеть (Postgres, Valkey, MinIO, хаб) - только публичный API.
- 🔜 gVisor - желательно с этапа 3, обязательно с этапа 5.
- 🔜 Бэкенд игры получает короткоживущий токен с `audience` = id игры, а не ключи хаба.

## Хаб и админка (этапы 1-2)

- 🔜 Сессионная кука `__Host-…`: без `Domain`, `Secure`, `Path=/` - игры с `*.play.youranus.ru`
  не смогут её перезаписать (cookie tossing).
- 🔜 CSRF - токены + проверка `Origin`; **SameSite не защищает**, игры same-site с хабом (D-010).
- 🔜 Вход в админку - passkey или 2FA; журнал действий.
- 🔜 Ключи S3 - зашифрованы мастер-ключом из файла `600`; ввод скрытый; показ - "задан, длина N".

## ИИ-агент (этап 4)

- 🔜 Агент - недоверенный исполнитель: работает в песочнице Builder'а без секретов.
- 🔜 Ключ API - через прокси хаба, в контейнер не попадает.
- 🔜 Файлы игры и наборы скиллов - недоверенный ввод (промпт-инъекции).
- 🔜 Результат агента идёт тем же конвейером: сборка → превью → публикация по кнопке человека.

## Секреты

Правила кита действуют целиком: секрет не попадает в командную строку, ввод - скрытый,
проверка - по наличию и длине. В репозитории секретов нет; `.env` в `.gitignore`,
`.env.example` - без значений-секретов.
