# Сценарии сайта Game Factory

Общие команды и правила — [проектный инструмент](../../README.md).
Цель: `hub`. Пример нового сравнения:

```bash
pnpm ui:baseline hub --ref HEAD --run header
pnpm ui:preview hub --run header
pnpm ui:check hub --run header
pnpm ui:live hub --run header
pnpm ui:verify hub --run header
pnpm ui:compare hub --run header
```

База берёт `apps/hub` из указанного commit, включая UI-исходники и public-ресурсы.
После берёт рабочие файлы. Временная Vite-сборка использует настоящие компоненты;
сессия, auth, API и bridge заменены только явными примерами `mocks.jsx`.
Next-приложение эти модули не импортирует. Настоящий вход образцами не доказывается.

11 состояний в config.ts: каталог/пустой каталог, игра/загрузка, вход/недоступная БД,
аккаунт/пустые passkey/ошибка, UI-kit и 404. Матрица: семь размеров, две темы,
две версии — 308 состояний. Сохраняются PNG, геометрия и ошибки; живой прогон
проверяет fullscreen, тач в landscape и forced-colors.

Серверы проверок поднимаются автоматически на свободных портах и закрываются в finally.
Ручное сравнение — порт4183, настраивается --port. Встроенная игра — пустая область;
auth/БД/bridge и содержимое iframe проверяются другими штатными тестами.

Существующая база перед пунктом6 и её артефакты скопированы из старого каталога сессии
в test-results/ui/hub; исходный каталог сохранён. В новой metadata hash — SHA HTML,
sourceHash сохраняет прежний хеш UI-исходников, artifactHash проверяет весь результат.
Старый зелёный отчёт не выдаётся за проверку перенесённого инструмента.
