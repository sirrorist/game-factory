# Сценарии Superwalk

Общий сервер и сборка находятся в [проектном инструменте](../../README.md).
Здесь только игровые сценарии, временная инструментализация и специальные проверки.

```bash
pnpm ui:baseline superwalk --ref HEAD --run inventory
pnpm ui:preview superwalk --run inventory
pnpm ui:check superwalk --run inventory
pnpm ui:live superwalk --run inventory
pnpm ui:verify superwalk --run inventory
pnpm ui:compare superwalk --run inventory
pnpm ui:boundary superwalk --run inventory
pnpm ui:wallet-review superwalk --run inventory
pnpm ui:acceptance superwalk --run inventory
```

Совместимые `pnpm --filter @gf-game/superwalk ui:*` делегируют корневому CLI.
Для действующего сравнения 1.1.0/1.1.1 не указывать --run и не создавать базу заново.
Исходная база811ae9b и дополнительная revision-before остаются отдельными источниками.

config.ts задаёт 23 состояния: HUD/полный инвентарь, босс, пауза/характеристики,
обзор Tab, прокачка, победа/поражение, уведомления/предмет с боссом и без него,
F3, все вкладки кошелька, крупный баланс, полная коллекция, ошибка и чек.
В семи общих профилях это 322 полных PNG и 322 PNG UI, плюс161 diff.

Сценарии fixtures.ts вызывают настоящие методы приложения через временный __SW_UI__.
Мир останавливается после кадра, RNG фиксируется; дата задаётся для подготовки,
во время кейса/взаимодействия часы продолжают идти. SDK ready и штатное определение
тач проверяются отдельно. Хук не добавляется в src/ или обычную сборку.
Миллион и полная коллекция — образцы геометрии, не доказательство начисления.

Live использует обычные Date/RNG/rAF/CSS. Семь общих профилей плюс шесть iframe:
990×680,464×620,350×620,790×290,790×341,600×290. Проверяются ввод/фокус,
анимации, раскрытие сумм, выдача кейса, resize/reopen/reload и весь кошелёк.
Редкий выигрыш проверяется отдельным явно обозначенным входом настоящему казино;
управляется вход, результат не подменяется. Это не проверка серверной экономики.

wallet-layout.ts проверяет hidden/clip, неожиданный scrollTop, границы строк,
пересечения, доступность закрытия до программной прокрутки и DOM Range числа.
Boundary: свежие790×341/600×290, координатные касания, операция/чек/закрытие,
22 размера без reload в обе стороны —192 состояния. Wallet-review —81 состояние;
acceptance — масштаб, resize, Tab-scroll/карта и fullscreen.

Результаты внутри выбранного каталога сравнения: report.json, shots/, diff/,
live-report.json, live/, tool-smoke.json, boundary/, wallet-review/, acceptance/.
Фильтр GF_UI_PROFILES делает static/live прогон частичным; SW_UI_PROFILES пока поддержан.
SW_UI_OFFLINE задаёт путь к распакованному обычному index.html для ui:verify.
Прерванный прогон и смена HTML/runner не оставляют зелёную приёмку.

Физические телефоны, Safari/Firefox, настоящий вход и проверка забега — отдельные задачи.
Исторические отчёты 1.1.1 в games/superwalk сохранены вместе с исходными доказательствами.
