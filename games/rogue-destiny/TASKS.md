# Rogue Destiny - рабочие задачи

Цель: красивый законченный забег по DESIGN.md. Работа только внутри этой игры.

## Порядок
- [ ] 01. Базовые проверки и воспроизводимые сценарии.
- [ ] 02. Перегрев, травма, расходники, честные ограничения действий.
- [ ] 03. Сохранение: ошибки, проверка данных, восстановление мира.
- [ ] 04. Перемещение, границы мира, камера, уклонение на ПК и таче.
- [ ] 05. Парирование, награды, состояния боя и поражение.
- [ ] 06. Условия портала, финальное испытание, завершение забега.
- [ ] 07. Генерация этажей, замки и доступные маршруты.
- [ ] 08. Лут, резонанс, применение и слияние свитков.
- [ ] 09. Модели из открытых источников: лицензия, локальные файлы, стилизация.
- [ ] 10. Свет, окружение, эффекты и читаемость сцены.
- [ ] 11. Все окна и тач, сравнение до/после.
- [ ] 12. Бюджет отрисовки, F3, освобождение ресурсов.
- [ ] 13. Полное прохождение, офлайн-архив, баланс и регрессии.

## Цикл
Одна задача: воспроизведение -> малая правка -> проверка логики -> сборка ->
браузерное прохождение и просмотр изображений -> запись доказательств.
Браузерные проверки выполняются в разрешённой среде по CLAUDE.md.
Галочки ставятся только с результатом команды или прохождения.
