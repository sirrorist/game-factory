План: [UI-REVISION-PLAN.md](UI-REVISION-PLAN.md). Пункт 7 начат после приёмки.

- Состав страниц сверён по маршрутам: каталог `/`, игра `/games/[id]`, вход `/login`,
  аккаунт `/account`, витрина `/kit`, общий 404. API и healthz не являются страницами UI.
- В globals.css добавлен общий масштаб по ширине/высоте CSS viewport: Full HD ×1,
  QHD ×1,33, 4K ×2. Нижняя граница — пользовательский начальный размер шрифта.
  Масштаб задаётся CSS без ожидания гидратации и пересчитывается при resize/fullscreen.
- 183 фиксированных значения CSS переведены из px в rem: типографика, кнопки, поля,
  иконки, шапка, отступы, радиусы, тени и компоненты витрины. Значения при масштабе ×1
  сохранены; Tailwind-контейнеры и типографика уже используют rem и масштабируются вместе.
- Отдельно исправлены inline-размеры логотипа, фиксированные размеры/шрифты UI-kit,
  демо витрины и высота внешнего iframe. В полном экране iframe остаётся на весь экран;
  кнопка выхода хаба использует общий масштаб и безопасный отступ.
- Длинное имя в шапке имеет ограниченную ширину и многоточие. По замечаниям приёмки
  мобильная шапка перестроена в две явные строки: логотип и вход/профиль сверху,
  навигация одинаковыми вкладками ниже. На телефоне профиль показан иконкой с доступным
  именем/подсказкой; полный текст имени остаётся в аккаунте. Цели в шапке — 48 px при ×1.
  На экранах до 379 px остаётся компактный знак и иконка выхода. Действия карточек допускают перенос.
- Содержимое iframe других игр и их исходники не менялись. Атрибуты sandbox/allow,
  проверка origin/source, авторизация, API и защитные заголовки хаба не менялись.
