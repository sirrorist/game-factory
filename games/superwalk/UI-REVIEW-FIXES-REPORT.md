# Superwalk 1.1.1 — исправления REVIEW-111

Исправлены четыре подтверждённые находки из [REVIEW-111.md](REVIEW-111.md).
Исходный отчёт и его доказательства сохранены. Прежний зелёный прогон действительно
не проверял скрытое переполнение и мог возвращать недоступную кнопку программной
прокруткой; считать его доказательством отсутствия этих дефектов нельзя.

## Исправления

| Находка | Изменение | Проверка |
|---|---|---|
| R1, P1: крестик исчезает после вывода в 790×290 | Заголовок не сжимается; панель не получает прокрутку при фокусе. Автофокус использует preventScroll. Для низкого landscape форма и чек перестроены в две колонки; содержимое помещается целиком. | Геометрия всей панели и заголовка после операции; закрытие касанием по координатам без scrollIntoView. |
| R2, P2: расчёт и сообщения перекрываются в 350×620 | Расчёт сохраняет минимальную высоту содержимого. В коротком портрете компактнее баланс, навигация в одну строку; сообщения имеют отдельное место. | Форма, ошибка, две стадии запроса и чек: границы текста, строк, секций и их пересечения. |
| R3, P2: проверки пропускают переполнение | Общая проверка wallet-layout включена в static/live. Проверяются hidden/clip, scrollTop, весь чек, заголовок, крестик, текст и глифы. Кошелёк проверяется до программной прокрутки. | На сохранённой проблемной сборке адресный прогон выявил 13 ошибочных состояний; после исправления — 0 из 81. |
| R4, P3: миллион перекрывает $GFC | Число и валюта не сжимаются; колонка учитывает их общую ширину. SVG-график не навязывает собственную минимальную ширину соседним подписям. | Отдельная сцена крупного баланса; реальные границы глифов проверяются относительно валюты и карточки. |

Для 790×290 также уплотнены слоты, кейсы и карточки скинов, сохранены кнопки касания
48 px и пагинация. Декоративный график в этой раскладке скрывается; баланс и курс видны.
Начисления, ставки, выплаты и серверная экономика этими исправлениями не менялись.

## Выполненные команды

Из корня worktree:

```bash
pnpm --filter @gf-game/superwalk typecheck
pnpm --filter @gf-game/superwalk test
node games/superwalk/ui/cli.ts check
node games/superwalk/ui/wallet-review.ts after
node games/superwalk/ui/cli.ts live
```

Типы прошли; 141 тест игры прошёл. Обычные build/export выполнены в отдельном временном
GF_DATA_DIR; ZIP 382352 байта. Экспорт распакован и проверен через file:// командой
`node games/superwalk/ui/smoke.ts` с SW_UI_OFFLINE, указывающим на обычный index.html.
В инструментальной фикстуре предмета отменяется штатный таймер скрытия только для
статического снимка: медленное получение 4K PNG больше не теряет всплывающий предмет.
В обычную игру это изменение не попадает.
