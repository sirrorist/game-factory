## Изменения

- Размеры интерфейса переведены в rem. Масштаб по доступной ширине/высоте:
  `max(1, min(width / 1920, height / 1080))`; обновляется при resize/fullscreen.
  Full HD ×1, QHD ×1,33, 4K ×2. Низкое широкое окно и обычные мобильные размеры — ×1.
- Меняются шрифты, кнопки, иконки, отступы, границы и размеры окон. Canvas, viewport,
  камера и экранные координаты не получают CSS-transform/zoom интерфейса.
- Пауза, тактический обзор, прокачка, кошелёк и итоги имеют общую ширину 50rem,
  ограниченную доступным пространством; одинаковые внешние безопасные отступы.
- Колонки обзора перестраиваются внутри общей ширины. Положение маркера карты,
  расстояние уведомлений и конечные позиции барабанов учитывают масштаб.
- Слоты движутся на долю высоты ленты; resize не меняет конечный символ. У кейса
  обновляется геометрия анимации без перезапуска её времени/операции.
- Просмотрщик по умолчанию сравнивает с сохранённой 1.1.1 до второго прохода;
  исходная 1.1.0 выбирается отдельно. По-прежнему два iframe с отдельными origins.
  В каждой колонке виден фактический процент предпросмотра и размер viewport.
- `ui:preview` собирает кандидат для приёмки без полного UI-прогона. Старые зелёные
  отчёты становятся недействительными, старые снимки/отличия не выдаются за новые.
