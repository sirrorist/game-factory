# Superwalk 1.1.1 — шаг 2: интерфейс и анимации

Статус: завершён; пауза перед шагом 3. Дата: 2026-10-13.
Порядок работы и паузы: [SESSION-PLAN.md](SESSION-PLAN.md).
Исходные находки: [STEP-1-REPORT.md](STEP-1-REPORT.md).

## Изменения

| Находка | Получившееся поведение |
|---|---|
| UI-01 | Ставка показана сразу; выигрыш раскрывается после остановки. HUD, сумма USD, Max и сообщения формы используют тот же отображаемый баланс. После остановки форма пересчитывается без повторного ввода |
| UI-02 | Кейс сразу заполнен карточками с иконками лиса. Лента движется в нужную сторону; центр выигрышной карточки рассчитывается по фактической геометрии. После остановки и resize победитель под маркером |
| UI-03 | Тёмное поле полной ширины, читаемые строки расчёта с промежутками, состояния ошибки. В форме целые суммы 1…1000000 согласно текущему диапазону операции; неверные значения отклоняются до этапов исполнения |
| UI-04 | У паузы одна прокрутка обзора; снаряжение и характеристики без своих скроллеров. Основные действия остаются вне обзора. На низком широком экране действия и обзор стоят рядом; у кошелька одна прокручиваемая панель |
| UI-05 | Четыре вкладки в ряд при ширине окна от 600 px; две колонки на узком окне. Вкладки не сжимаются и не прокручиваются внутри себя |
| UI-06 | У чека отдельный отступ между кнопкой нового вывода и нижним текстом; строки деталей переносятся при нехватке ширины |
| UI-07 | Tab/Shift+Tab следуют порядку доступных элементов кошелька и остаются внутри. Escape возвращает фокус инициатору; при открытии из паузы возвращается сама пауза. Фон временно inert, прежние значения восстанавливаются |
| UI-08 | Max учитывает лимит и доступную отображаемую сумму; ошибка суммы видна до имитации подписания. После отказа операции можно повторить запрос |

Игровой **Tab сохранён**: нажатие открывает тактический обзор, отпускание закрывает его.
Space, стрелки и Ctrl/Meta+A работают нативно в форме при неактивном игровом вводе.
F3 работает в паузе и изолирован от кошелька/финала.

Слоты и кейс используют Web Animations: время анимации продолжается при скрытом кошельке.
Перед показом результата анимация явно снимается, окончательная позиция фиксируется.
Выполняется одна операция; параллельные дорогие действия заблокированы, вкладки и закрытие
доступны. Закрытие/повторное открытие сохраняет результат и не повторяет списание.

Независимые проверки нашли дополнительные UI-дефекты, исправленные в пределах шага:

- Снаряжение накладывалось на характеристики после снятия вложенных ограничений высоты:
  строки обзора теперь имеют высоту содержимого; добавлены проверки пересечений.
- Выигрыш утекал через Max/ошибку доступной суммы; все видимые суммы согласованы.
- При resize таймер результата мог опередить первый кадр анимации: активная анимация
  снималась позже расчёта центра; теперь сначала снимается, потом выравнивается.
- MOB-01: toast закрывал подписи итогов в горизонтальном телефоне. Игровая обратная связь
  скрыта на финале; результат и повторный запуск представлены внутри итоговой карточки.
  При рестарте прежние уведомления очищаются и обычная обратная связь возвращается.
- MOB-02: в iframe 790×290 toast F3 временно закрывал подпись «Продолжить» при доступном
  клике. Feedback скрывается в паузе; состояние переключателя видно на кнопке. После
  выхода из паузы обычная видимость восстанавливается. Добавлены живые проверки обоих
  состояний: доступность клика сама по себе не доказывает читаемость подписи.

## Ограничения и следующий шаг

Chromium с эмуляцией касаний и самостоятельной оболочкой iframe; физический телефон,
Safari/Firefox, жесты пальцем, настоящий хаб/авторизация и физический масштаб 4K не проверены.
Оценка владельцем намеренных визуальных изменений остаётся отдельной приёмкой.
Сравнение: `pnpm --filter @gf-game/superwalk ui:compare`, http://127.0.0.1:4179;
две версии, каждая отдельно/обе, сценарии/снимки/обычная игра.

Серверная экономика, подписи, честность наград/забегов, защита сохранений и потеря джекпота
остаются шагами 3–5. Исправленные ограничения формы улучшают UI; подтверждённого онлайн-баланса
этот шаг не создаёт. Коммит, push и выкладка не выполнялись.
