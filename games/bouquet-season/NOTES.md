## Устройство и сохранённые решения

- Состояние/расчёты отдельно от Phaser/DOM. Схема 6 строго проверяет 1–5 до миграции; чтение не пишет, следующая запись вращает исправную копию без переигрывания RNG/заказов/наград.
- Проверяются форма, целые числа, открытия, контуры, истории, награды и сроки; SHA-256 точного payload, вся запись UTF-8 ≤64 КБ. Повреждённая основная не вращается в резерв. `persistent:false` блокирует сезон; повтор hub-записи не уходит в standalone.
- Поле во весь viewport; drawer slide/fade 240 мс блокирует ввод, поддерживает Esc/фон/цикл фокуса. Ошибка/pending/итог удерживают панель; при нехватке места скролл, без уменьшения текста.
- [UI-LAYOUT](../../docs/UI-LAYOUT.md): Full HD ×1, QHD ×4/3, 4K ×2; панели 600/800/1200, цели ≥48/64/96 px. NativePointerEvents, физические WASD/ФЦЫВ/стрелки, колесо/средняя/два пальца; ПКМ отменяет режим либо открывает каталог пустой клетки.
- Все выставляемые объекты и превью с контуром, подсветка ниже объектов, значки ухода выше тени. Устройства не подсвечиваются как получатели зон других устройств.
- День только с активным основным: сроки/штрафы вместе → итог при нулевой репутации/дне 20 → иначе один рост → предложения/события. Без роста 21/бесплатного календаря. Без активного заказа доступно подтверждённое поражение.
- Рост: 2 базовые половины +1 допуход +1 сосед, порог 8/минимум два дня. Увядание 1/2/гибель 3; восстановление/адаптация без роста. Зрелый урожай фиксируется; срезка сохраняет растение, запас не портится.
- Урожай 2, +1 за другой вид весь цикл либо P5/устройство/модуль весь цикл; истории не складываются. Срезка/день/сдача/модуль закрывают undo; перенос сохраняет модуль, удаление возвращает его.
- Все P1–P6/E1–E6 реализованы. P1 меняет уход, P2/P3 передают условие один шаг, P3 только от прямого поливателя, P4 меняет соседа скорости, P5 подпорка, P6 свой свет. E1/E2 дальность q/r; E3 заимствует только собственную зону соседа; E4 оба условия; E5 кольцо 12; E6 ближние 6 + шесть углов.
- Заказы 8/14/20/26/32 + подарок; 2 монеты/1 XP за цветок. Финал 48 из 2–4 открытых видов, 96 монет/96 XP; пятый выбор до генерации финала. Срок min(появление+5/7,20), принятие не продлевает.
- До двух основных/просьб. Свободная опубликованная тройка сохраняет ID/состав/срок/RNG при сдаче соседнего заказа/pending/reload. Пять ступеней сдаются в любом порядке по одному разу; финал после пяти сдач/выборов.
- Ярмарка: объявление 3, приём 6–10; минимум 8+8 →48/16, пропуск −1 репутация; допцель 6+6 →36/12+выбор без штрафа. Общий стебель один раз; риск потери готовности обязательной цели требует подтверждения.
- Деньги зачисляются при итоге один раз; поражение теряет floor(доход/4), старые деньги/весь XP сохраняются. Победа закрывает будущие события без наград/штрафов.
- Уровни 2–5:60/180/360/600 XP; роза 60/L2, тюльпан 80 и основное место 120/L3, гербера 100/поле37 за200/событийное100/L4, лилия120/L5. Покупки независимы, однократны, только между сезонами; `season.access` фиксируется на старте.
- Первый настоящий заказ: шесть контекстных подсказок, пропуск без отмены заказа/награды; профиль помнит освоенные шаги даже при выключенных подсказках. Планировщик ищет свидетельство, его отказ не доказывает невозможность.

## Безопасность релиза

- Решение владельца 2026-11-05: выпустить 1.0 с обфускацией, серверную проверку позже. Подмена собственного прогресса остаётся возможной и принята; этот прогресс не используется в общей экономике/рейтинге.
- Hub текущей копии сохраняет в localStorage хаба; SHA защищает от повреждения, не от накрутки. Подписей игровых транзакций/серверной авторитетности сейчас нет. Прод-код самостоятельно не проверен.
- В [SECURITY.md](../../docs/SECURITY.md#игровой-прогресс-античит-и-защита-исходников) и AGENTS закреплены общие правила доверия клиенту, серверных команд, подписей, revision/idempotency, миграции и обфускации. Три соседние рабочие копии прочитаны; ветки через Git не проверялись.
- `javascript-obfuscator@5.10.0` — точная dev-зависимость только игры, установка без scripts; lockfile обновлён. Сборка обрабатывает свои src, не Phaser/SDK; фиксированный seed, публичные JSON/API-поля сохранены, приватные члены — #private. Секреты в клиент не добавлялись.
- Build включает проверку готового пакета: нет исходных TS/карт (внешних/hidden/inline), обязательна обработка main. Маркер — контроль сборки, не подпись подлинности. Публичный репозиторий остаётся публичным.
- Независимое security-ревью закрыло находку о недостающих отрицательных проверках; полная проверка всех транзитивных зависимостей/секретов и прод-среды не выполнен.
