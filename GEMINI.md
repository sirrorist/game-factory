# Game Factory - вход для агентов

Текст один для всех агентов и живёт в `AGENTS.md`; Gemini CLI подключает его отсюда.

@AGENTS.md

## Протокол работы агента (Gemini)
1. **Задачи:** выявить первопричины дефектов и зафиксировать список задач в артефакте `tasks.md`.
2. **План:** сформулировать ясный технический план и согласовать с пользователем ДО написания кода.
3. **Реализация:** аккуратное внесение изменений strictly в директорию игры (`games/<id>/`).
4. **Проверка:** обязательное написание регрессионных тестов (старый функционал не ломается, новый работает строго по ТЗ), прогон полного пайплайна (`test`, `typecheck`, `validate`, `games:build`, `shots`).
